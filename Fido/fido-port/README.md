# FIDO v1.8 — порт для современных систем

Игра Юрия Нестеренко «FIDO» (© YuN 1997–99), перенесённая с Borland C++ / DOS
на современный C++. Работает в терминале на macOS и Linux, без DOSBox и без
сторонних библиотек.

## Сборка и запуск (macOS)

Нужны только Xcode Command Line Tools (`xcode-select --install`), если они
ещё не стоят.

```sh
make
./fido          # новая игра
./fido load     # загрузить сохранение (как в оригинале: любой параметр)
```

Окно терминала должно быть не меньше 80×25. Если оно меньше, игра попросит
терминал увеличить окно, а если это не выйдет — покажет подсказку. В окне
большего размера экран 80×25 рисуется по центру.

Подойдут Terminal.app, iTerm2, Ghostty, WezTerm и другие. Если терминал
сообщает поддержку 24-битного цвета (`COLORTERM=truecolor`, например iTerm2),
используется точная палитра VGA, иначе — ближайшие цвета из 256-цветной
палитры. Принудительно включить 256 цветов: `FIDO_256COLOR=1 ./fido`.

## Управление

Как в оригинале: буквы из нижней строки (`G`ame, `B`BS, `U`pgrade, `J`ob,
`L`earn, `S`oft, `E`choes, `P`oints, `F`riends, `T`ime, `N`ext day), стрелки,
Enter, Esc, пробел. `Q` — выход без записи, `W` — выход с записью.

На клавиатурах Mac без PgUp/PgDn они не нужны: везде работают стрелки.
Русские буквы при вводе названий BBS и эх набираются обычной раскладкой.

## Файлы данных

Каталог `data/` содержит файлы из дистрибутива 1.8: `README.FID` (без него
игра не запускается, как и оригинал) и заставки BBS `1.BIN`…`10.BIN`.
Сохранение `fido.dat` и журнал `log` (Game → Log on) пишутся туда же.
Каталог ищется рядом с программой, другой можно указать через
`FIDO_DATA=/путь ./fido`.

Журнал теперь в UTF-8. Сохранения DOS-версии с портом несовместимы.

## Как устроен порт

* `src/fido.cpp` — игра. Изменения помечены комментариями `// port:`.
* `src/wnds.cpp`, `src/date.cpp` — оконная библиотека автора и работа с
  датами в формате DOS, переведённые с K&R C на современный C++.
* `src/term.cpp`, `src/compat.h` — слой совместимости: эмуляция видеопамяти
  текстового режима VGA (8 страниц, байт символа + байт цвета), вывод в
  терминал через ANSI-последовательности, клавиатура с DOS-кодами,
  `gettext/puttext`, генератор случайных чисел Borland C (15 бит — от этого
  зависят вероятности событий в игре).

Внутри игра, как и оригинал, работает с текстом в CP866: от этого зависит
вся раскладка окон (ширина по `strlen`, посимвольная запись в видеопамять).
Исходники хранятся в UTF-8, а `make` перекодирует их в CP866 (`iconv`) в
каталог `build/` перед компиляцией. В Unicode текст переводится только при
выводе на экран.

### Что заменено

* Ассемблерные вставки (таймер PIT, BIOS `int 10h`, DOS `int 21h`) —
  на POSIX-вызовы.
* Прямая запись в `B800:0000` — на буфер `vram`, который отрисовывается в
  терминал изменёнными ячейками.
* Сохранение: оригинал писал сырые куски памяти (зависело от раскладки
  переменных компилятором Borland) и шифровал XOR-ом с ключом из даты файла.
  Теперь каждое поле пишется явно, файл защищён XOR-ом и контрольной суммой.
* Графическая заставка `fidologo.bmp` (VESA 640×480) не перенесена: в
  дистрибутиве 1.8 этого файла нет, и оригинал без него её просто пропускает.

### Исправленные ошибки оригинала

Исправлено то, что в DOS сходило с рук, а на современной системе приводит к
падению или неопределённому поведению. Баланс игры не менялся.

* Запись в строковые литералы (префикс города, название своей BBS, описания
  своих эх) — теперь это изменяемые буферы.
* `input()` редактировал копию строки, выделенную по её текущей длине, и
  писал за её конец при вводе более длинного текста.
* Буферы `sprintf` меньше выводимого текста (`showstat`, `showtime`,
  `vircheck` и др.) — `salloc()` теперь выделяет не меньше 256 байт.
* Покупка железа читала цену за концом массива, когда денег хватало на
  самую дорогую модель.
* `ar[i]=comp[i++]` и `scr[..i..]=st[i++]` — неопределённый порядок
  вычислений (в C++17 такой код сдвигает текст на символ).
* Возврат долга при нехватке денег вычитал неинициализированную переменную.
* Функции `event()` четырёх эх ничего не возвращали.
* При удалении своей эхи из середины списка две эхи начинали делить один
  буфер описания.
* Дата окончания курсов при переходе через год (месяц 13 становился
  февралём).
* Escape-последовательности в строке подсказок: `\e` в Borland означал
  букву «e», а в современных компиляторах — символ ESC.
* Окно установки ОС не закрывалось при «глюках».

### Мелкие удобства

* Финальную «растворяющуюся» заставку можно ускорить любой клавишей.
* `FIDO_FAST=1` убирает все паузы (для автоматических тестов).

# 03. Бэкенд: язык, пакеты, архитектура

## Язык и среда

**TypeScript на Node.js.** Один язык с клиентом, общая схема протокола и модели. Под агентную
разработку это сильный выбор. Wiren Board тянет Node без проблем.

## Процессы

- **Ядро** (`apps/core`): модель дома, состояние, поведения, сцены, журнал, API для клиентов.
- **Драйверы** — отдельные процессы (`apps/drivers/*`): KNX, Wiren Board / Modbus, Matter, Zigbee
  (через Zigbee2MQTT), ИК, медиа (матрицы, ресиверы, Apple TV / Kodi), камеры. Связь с ядром — по
  MQTT, брокер Mosquitto уже есть на Wiren Board. Упал драйвер — ядро живо, драйвер
  перезапускается.
- **Облачный агент** (`apps/cloud`): исходящее WSS-соединение с объекта в облако. Даёт удалённый
  доступ жильцам и программисту без проброса портов.
- **Клиенты:** приложение жильца (`apps/client`), сервисная панель (`apps/service`),
  симулятор для демо и тестов (`apps/sim`).

## Пакеты

| Задача | Пакет |
|---|---|
| HTTP + WebSocket | `fastify`, `ws` |
| Схемы и валидация | `@sinclair/typebox`, `ajv` |
| Хранилище | `better-sqlite3` + `kysely` |
| Версии проекта объекта | `isomorphic-git` |
| MQTT | `mqtt` (mqtt.js) |
| KNX | `knxultimate` |
| Matter | `@matter/main` (matter.js) |
| Zigbee | Zigbee2MQTT (отдельный сервис) |
| Камеры, видео в браузер | `go2rtc` (отдельный сервис) |
| Логи | `pino` |
| Расписания | `croner` |
| Солнце (рассвет, закат) | `suncalc` |
| Очереди команд с ограничением | `p-queue` |

## Развёртывание

- Пакет `.deb` + systemd.
- Версии лежат в каталогах A/B, переключение — симлинком, откат — на предыдущий каталог при
  неудачном старте.
- Обновления — с облачного агента, по объекту или волной по парку.

## Монорепозиторий (целевая структура)

```
packages/
  protocol/     # типы протокола: команды, дельты, snapshot (сейчас src/core/types.ts)
  model/        # схема проекта объекта (TypeBox), валидация, миграции
  driver-sdk/   # общий каркас драйвера: MQTT-топики, профили, здоровье
apps/
  core/
  drivers/*
  client/       # этот прототип
  service/      # сервисная панель
  cloud/
  sim/          # симулятор (сейчас src/core/sim.ts)
```

Перенос прототипа:
1. `src/core/types.ts` → `packages/protocol`.
2. `src/core/houses/*` → примеры проектов в `packages/model/examples`.
3. `src/core/sim.ts` → `apps/sim`.
4. Остальное → `apps/client`.

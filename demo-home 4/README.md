# Демо-дом — прототип клиента умного дома

Svelte 5 + TypeScript + Vite, WebGL-шейдеры и three.js. Бэкенд не нужен: дом симулируется в браузере
и говорит тем же протоколом, что будет у сервера на объекте.

```
npm install
npm run dev        # разработка, http://localhost:5173
npm run build      # сборка в dist/
npm run artifact   # сборка + одна страница dist/artifact.html (фото лежат рядом в dist/photos)
```

## Как устроено

| Слой | Где | Что |
|---|---|---|
| Протокол | `src/core/types.ts` | capabilities, `HomeState`, snapshot + delta, команды, интерфейс `Transport` |
| Конфигурация объекта | `src/core/house.ts` | комнаты, план, устройства, хотспоты на фото, сцены, камеры, зоны |
| Симулятор | `src/core/sim.ts` | `HouseSim implements Transport`: задержка, плавные переходы, присутствие, события |
| Состояние клиента | `src/client/store.svelte.ts` | `$state`-зеркало дома; замена симулятора на WebSocket — одна строка |
| Тренды | `src/client/theme.svelte.ts`, `src/themes.css` | токены (цвет, шрифт, форма, движение) + флаги возможностей + скины контролов + раскладки |
| Графика | `src/client/gl/*`, `src/client/three/*` | свет поверх фото, живой фон, 3D-модели и постеры устройств |
| Экраны | `src/screens/*` | план, комната, обзор, участок, охрана, главная, климат, медиа, устройство, AR |

Пути в дельтах: `devices|<id>|<key>` для устройств (id содержат точку), остальное — через точку.

## Новый тренд

1. Блок токенов в `src/themes.css` для `[data-trend="<id>"]` и двух режимов (`day`/`night`).
2. Запись в `trends` в `theme.svelte.ts`: какие возможности включены, какие скины контролов, какая раскладка.

Экраны трогать не нужно: они спрашивают тренд о возможностях, а не проверяют его имя.

## Демо-пульт

Кнопка «Демо» внизу справа: тренд, время суток на объекте, профиль (iPad / телефон в рамке),
события (звонок, движение, протечка) и переход на любой экран. В продукт не входит.

Адреса экранов: `#plan`, `#room-kitchen`, `#overview`, `#house`, `#security`, `#home`, `#climate`, `#media`, `#lamp-living-dining`, `#ar`.

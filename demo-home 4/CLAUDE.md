# CLAUDE.md — контекст проекта

Этот файл — точка входа для Claude Code. Здесь коротко: что за проект, в каком он состоянии,
как с ним работать. Подробности — в `docs/`, по одному файлу на тему.

## Что это

Прототип **собственной платформы умного дома** — заготовка под бизнес. Автор — бывший интегратор:
много лет Crestron (ещё VT Pro), потом JS-фреймворки. Опыт: заказные инсталляции по полгода,
3–4 объекта в год, круглосуточная поддержка, парк из нескольких десятков объектов, обновление
раз в 3–4 года.

Идея платформы:
- **Железо открытое:** контроллер Wiren Board. Оконечные устройства — KNX для люкса,
  Matter/Zigbee для бюджетных объектов.
- **Весь софт свой.** Главная ставка — клиентское приложение с эксклюзивным дизайном под каждого
  заказчика и бесшовной интеграцией в архитектурный проект и дизайн интерьера.
- **Разработка с ИИ-агентами:** считаем, что они снимают прежние ограничения по срокам.

Рабочие названия из буклета — компания **«Анфилада»**, продукт **«Свод»**. Это заглушки,
настоящие названия пока не светим.

Подробнее о продукте и бизнесе: `docs/00-context.md`.

## Команды

```
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/
npm run artifact   # dist/ + одностраничный dist/artifact.html (фото рядом в dist/photos)
npx tsc --noEmit   # проверка типов (svelte-check в этой конфигурации не настроен)
```

Объект переключается в пульте «Демо» (правый нижний угол) → «Объект». Выбор хранится в
`localStorage['dd.project']`, запасной путь — `window.name`. Переключение перезагружает страницу.

Скрипты Playwright ждут собранное приложение на `vite preview --port 4173`:
- `node scripts/shot.mjs <route> <WxH> <out.png> <trend>` — один экран;
- `node scripts/nav.mjs <outdir> [typical|demo]` — прогон новой навигации на телефоне и iPad;
- `node scripts/load.mjs <outdir>` — нагрузочный прогон типового объекта.

## Как устроен клиент (коротко)

- **Протокол** — `src/core/types.ts`:
  - capabilities устройств, `HomeState`, snapshot + delta, команды, интерфейс `Transport`;
  - пути в дельтах: `devices|<id>|<key>` (id устройств содержат точку), остальное через точку.
- **Конфигурация объекта** — `src/core/house.ts` выбирает `demo` или `typical`:
  - `HouseDef`: комнаты с этажами, план, устройства, фото и хотспоты, сцены, камеры, зоны охраны,
    избранное, начальное присутствие;
  - устройство: `caps` + `kind` (ставни/жалюзи/рулонная, проектор, консоль, духовка…), `readonly`,
    `init` (начальное состояние в симуляторе), `glow` (пятно света на фото).
- **Симулятор** — `src/core/sim.ts`, `HouseSim implements Transport`:
  - плавные переходы, присутствие, датчики, вентиляция по присутствию, события охраны, мощность;
  - доступен как `window.__sim`.
- **Состояние клиента** — `src/client/store.svelte.ts`: `$state`-зеркало дома. Замена симулятора
  на WebSocket — одна строка.
- **Навигация** — `src/client/nav.svelte.ts`: группы устройств, этажи, «где я», активные комнаты,
  поиск, зоны медиа, климатические комнаты. Маршруты — `src/client/router.svelte.ts`, hash-роутинг
  `#name-arg`.
- **Тренды** — `src/client/theme.svelte.ts` и `src/themes.css`: токены, флаги возможностей
  (`ambient`, `relight`, `posters`, `planGlow`), скины контролов, варианты раскладки.
- **Графика** — `src/client/gl/*` (перерисовка света на фото, живой фон),
  `src/client/three/*` (3D-модели и постеры устройств).

## Договорённости

- Интерфейс и комментарии — на русском. Тексты интерфейса короткие, без канцелярита.
- Svelte 5 runes, без сторонних UI-библиотек. Состояние — модули `.svelte.ts`.
- Всё, что зависит от объекта, берётся из `HouseDef`. Не хардкодить id устройств в экранах:
  для этого есть `house.favorites`, поиск по `caps`/`kind` и хелперы в `nav.svelte.ts`.
- Новый тип устройства — это capability в `types.ts`, ветка в `DeviceRow.svelte`
  (иконка, состояние, переключатель), группа в `nav.svelte.ts → groupOf()` и инициализация в `sim.ts`.
- Хранилище браузера — только в `try/catch`: в песочнице артефакта оно может быть недоступно.
- Тренд minimal переопределяет радиусы и типографику через `:global([data-trend="minimal"])`.
  Новые компоненты должны это учитывать.
- Анимации уважают `prefers-reduced-motion`.

## Известные ловушки

- `Slider`: класс скина — `s-fill`/`s-hairline`. Класс `.fill` конфликтовал с корнем.
- `Segmented` меряет активную кнопку через ResizeObserver. Равные колонки не годятся:
  длинные подписи вылезают.
- Прокрутка запоминается по ключу `route|arg`. Её `$effect.pre` в `App.svelte` должен стоять
  после объявления `name`, иначе TDZ.
- На телефоне колонки сетки — `minmax(0,1fr)`, иначе длинный контент распирает страницу.
- В `.dc.html` (сервисная панель) не класть `<sc-for>` внутрь `<svg>`. Пути считать строками в
  `renderVals`, подписи делать HTML-оверлеем. Подробнее — `design/README.md`.
- Маркеры на плане типового объекта разложены сеткой автоматически. Настоящие координаты должны
  приходить из редактора плана.

## Тренды со своим характером (8 ноября 2026)

Четыре тренда: «Тёплый вечер» (тяжёлый люкс), «Минимализм» (базовый), «Нордик», «Брутализм». Подстраницы общие, но у каждого тренда
**своя первая страница «Дом»** и **своя навигация**:

| Тренд | «Дом» (`src/skins/<id>/Home.svelte`) | Навигация (`src/skins/<id>/Nav.svelte`) |
|---|---|---|
| warm | дом на весь экран, стекло поверх: лифт этажей, слои, лента живых комнат | тёмная стеклянная панель с латунной кромкой, активная — тёплый отсвет |
| minimal | лист спецификации: часы, таблица цифр, белый макет с выносками (`Diorama` с `look: 'clay'`), указатель этажей | базовая плоская полоса без значков |
| nordic | деревянная модель на дубовом подносе, этажи — камешки, слои — «баночки», комнаты карточками с фото | льняная полка с дубовой кромкой, свои значки (дом с трубой, чашка, приёмник, камин, ключ), шалфейный «камешек» под активным |
| brutal | плакат: цифры в клетках, «РИС. 1» с линейками и растром, сырой список ссылок | строка «[01] ДОМ ——— ОГЛАВЛЕНИЕ», оглавление на весь экран; цифры 1–5 на клавиатуре. Командная строка отложена в `brutal/Command.svelte` |

- Общая механика страницы «Дом» — `src/client/domscene.svelte.ts` (`DomScene`: слои, этажи, подписи, жесты, `stats()`).
- Форма трендов поверх токенов — `src/brutal.css`, `src/nordic.css` (префикс `:root[data-trend=…]` ради веса).
- Растр Байера — проход в `src/house/tilt.ts` (`setDither`), включается флагом `features.dither`.
- Первая страница приложения — **«Сводка»** (бывшая «Главная»), на телефоне и на iPad. У каждого тренда своя:
  `src/skins/<id>/Summary.svelte`, выбор — `src/screens/Summary.svelte`. Базовая (фото-карточки, стекло) осталась у warm;
  minimal — журнальная полоса с таблицами; nordic — записка на льне, сцены-камешки, фото комнат; brutal — газета «ВЕСТНИК»:
  главная новость-подсказка, сцены-штампы, коллаж комнат-наклеек (двигаются, раскладка в `localStorage['br.collage']`), приборы с ASCII-шкалами.
